Integration

Belken Studio × TikTok

Belken Studio is an AI video creation and publishing platform by Belken. Our TikTok integration lets an authenticated user securely connect their own TikTok account and publish or schedule video content to it directly from the Belken Studio dashboard. We never post without the account owner’s action and authorization.

At a glance

Sign-in
TikTok’s official Login Kit / OAuth screen
Posting
TikTok Content Posting API, to the user’s own account
Scopes
user.info.basic · video.upload · video.publish
Control
Nothing is sent to TikTok until the user confirms. Revoke access anytime.

End to end

How it works (end‑to‑end)

  1. 01

    Connect: The user clicks “Connect TikTok” in the Belken Studio dashboard and is sent to TikTok’s official Login Kit / OAuth screen, where they review and approve the requested permissions.

  2. 02

    Authorize: TikTok returns an access token scoped only to the permissions the user approved. Belken Studio stores this token securely and uses it solely on the user’s behalf.

  3. 03

    Create & review: The user uploads or selects a video and writes a caption inside Belken Studio. Nothing is sent to TikTok until the user confirms.

  4. 04

    Publish or schedule: On the user’s command, Belken Studio uses the TikTok Content Posting API to upload the video to the user’s own TikTok account, immediately or at a scheduled time the user chooses.

  5. 05

    Disconnect anytime: The user can revoke access at any time from the Belken Studio dashboard or from their TikTok account settings, which immediately ends Belken Studio’s access.

Scopes

Permissions we request, and why

user.info.basic

Read the connected account’s basic profile (display name and avatar) so the user can confirm which TikTok account they are posting to.

video.upload

Upload a video the user created into their own TikTok account as a draft for the user to review and post.

video.publish

Publish or schedule the user’s video to their own TikTok account when the user explicitly chooses to post.

Privacy

Your data & control

Belken Studio accesses TikTok data only to provide the features above. We do not sell TikTok data, and we do not share it with third parties except the infrastructure providers required to operate the service. For full details on what we collect, how we use it, how long we keep it, and how to delete it, see our Privacy Policy. Your use of the integration is governed by our Terms of Service.
